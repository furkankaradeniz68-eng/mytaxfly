Authentifizierung

Alle Anfragen erfordern deinen API Key im X-API-Key Header.

X-API-Key: mtf_live_xxxxxxxxxxxxxxxx

Das System läuft aktuell im Testmodus — Briefe werden erstellt, aber nicht physisch versendet. Kein Handlungsbedarf auf deiner Seite.

Ablauf

Empfohlener Ablauf für eine unterschriebene Einreichung:

  • 1. POST /preview-filing mit Formulardaten aufrufen → pdf_base64 erhalten
  • 2. PDF dem Kunden zur Prüfung und Unterschrift zeigen
  • 3. POST /submit-filing mit signed_pdf_base64 aufrufen → Brief geht ans IRS
  • 4. Statusänderung per Webhook empfangen (wenn konfiguriert)

Vorschau generieren

POST/api/partner/preview-filing

Generiert das Steuerformular als PDF und gibt es als Base64 zurück. Damit kannst du dem Kunden eine Vorschau zum Unterschreiben zeigen.

FeldTypBeschreibung

form_typeerforderlichSiehe Formular-Typen unten
tax_yearerforderlichZahl, z.B. 2024
company.nameerforderlichName der LLC
company.einerforderlichEIN, z.B. "12-3456789"
company.address.cityerforderlichRegistrierte Stadt
company.address.stateerforderlich2-Buchstaben-Staat, z.B. "DE"
company.address.streetoptionalStraße
company.address.zipoptionalPostleitzahl
foreign_ownererforderlich für 5472_1120Objekt mit name, country

financialsoptionalFinanzdaten-Objekt
extend_formoptionalFür 7004: Formular das verlängert wird, Standard "1120"

Response

{ "pdf_url": "https://...", // signed URL, valid 24h "pdf_base64": "JVBERi0x...", // full PDF as Base64 "form_type": "5472_1120", "tax_year": 2024, "external_id": "client_001" }

Einreichung absenden

POST/api/partner/submit-filing

Reicht das Formular per physischem Brief beim IRS ein. Zwei Modi:

  • Mit signed_pdf_base64: Unterschriebenes PDF direkt hochladen — Generierung wird übersprungen
  • Ohne signed_pdf_base64: Wir generieren das PDF und fügen einen E-Signatur-Block ein

Request Body

FeldTypBeschreibung
external_iderforderlichMuss mit dem preview-filing Aufruf übereinstimmen
form_typeerforderlichSiehe Formular-Typen unten
tax_yearerforderlichZahl
companyerforderlichWie bei preview-filing
signer_nameerforderlichVollständiger Name des Unterzeichners
signer_titleerforderlichTitel, z.B. "Managing Member"
signed_pdf_base64optionalUnterschriebenes PDF als Base64 — überspringt die Generierung
ip_addressoptionalIP-Adresse des Kunden für E-Signatur-Nachweis
foreign_ownererforderlich für 5472_1120Wie bei preview-filing
transactionsoptionalWie bei preview-filing
partnerserforderlich für 1065Wie bei preview-filing

Response

{ "filing_id": "uuid...", "status": "faxed", // oder "submitted" "letter_id": "ltr_...", // Brief-ID "tracking_number": "9400...", // USPS Tracking "expected_delivery": "2024-04-05", "pdf_url": "https://...", // gültig 7 Tage "external_id": "client_001", "form_type": "5472_1120", "tax_year": 2024 }

Doppelte Einreichungen (gleiche external_id + form_type + tax_year) werden mit HTTP 409 abgelehnt.

Status abfragen

GET/api/partner/filing-status?filing_id=uuid

Gibt den aktuellen Status einer einzelnen Einreichung zurück.

{ "filing_id": "uuid...", "status": "faxed", "letter_id": "ltr_...", "created_at": "2024-03-15T10:00:00Z" }

Alle Einreichungen

GET/api/partner/filings

Gibt alle Einreichungen deines Partner-Accounts zurück, neueste zuerst (max. 200).

{ "filings": [ { "id": "uuid...", "external_id": "client_001", "company_name": "Marcel's Ventures LLC", "company_ein": "12-3456789", "form_type": "5472_1120", "tax_year": 2024, "status": "faxed", "created_at": "2024-03-15T10:00:00Z" } ] }

Einstellungen

GET/api/partner/settings

Gibt deine Partner-ID und aktuelle Webhook-URL zurück.

PATCH/api/partner/settings

Webhook-URL aktualisieren.

// Request body { "webhook_url": "https://dein-system.com/webhook" } // Auf null setzen zum Entfernen { "webhook_url": null }

Webhooks

Webhook-URL in den Einstellungen hinterlegen. Wir senden bei jeder Statusänderung einen POST mit Content-Type: application/json und dem Header X-MyTaxFly-Event.

Events

  • filing.submitted — Einreichung erstellt, Brief ausstehend
  • filing.mailed — Brief per USPS Certified Mail versendet
  • filing.failed — Ein Fehler ist aufgetreten

Payload

{ "event": "filing.mailed", "filing_id": "uuid...", "external_id": "client_001", "form_type": "5472_1120", "tax_year": 2024, "status": "faxed", "letter_id": "ltr_...", "tracking_number": "9400...", "timestamp": "2024-03-15T10:05:00Z" }

Dein Endpunkt muss innerhalb von 10 Sekunden HTTP 2xx zurückgeben. Fehlgeschlagene Zustellungen werden im Webhooks-Tab protokolliert.

Formular-Typen

form_typeBeschreibung
5472_1120Form 5472 + Form 1120 — foreign-owned single-member LLC (häufigster Fall)
1065Form 1065 — Partnership Return
1120Form 1120 — C-Corporation Return
5472Form 5472 einzeln
7004Form 7004 — Fristverlängerungsantrag

Alle Einreichungen werden per USPS Certified Mail an das IRS versendet. LLCs werden ohne US-Geschäftssitz angenommen (P.O. Box 409101, Ogden UT 84409 für 1065/1120; PIN Unit für 5472+1120).
