Authentifizierung

Alle Anfragen erfordern deinen API Key im X-API-Key Header.

X-API-Key: mtf_live_xxxxxxxxxxxxxxxx

Der API Key wird dir von MyTaxFly bereitgestellt. Halte ihn geheim — er identifiziert deinen Partner-Account eindeutig.

Ablauf

Empfohlener Ablauf für eine Einreichung mit Kundenunterschrift:

  • 1. POST /preview-filing → PDF als pdf_base64 erhalten
  • 2. PDF dem Kunden zur Prüfung und Unterschrift zeigen
  • 3. POST /submit-filing mit signed_pdf_base64 → Brief wird physisch per USPS Certified Mail ans IRS versendet
  • 4. Statusänderung per Webhook empfangen (optional)

Alternativ: submit-filing ohne signed_pdf_base64 — wir generieren das PDF und fügen automatisch einen E-Signatur-Block ein.

Testmodus

Mit "test": true im Request Body wird die Einreichung als Test markiert: ein Lob-Test-Brief wird erstellt (nicht physisch versendet) und die Einreichung erscheint im Dashboard mit dem TEST-Badge. Test-Einreichungen werden in den Statistiken nicht mitgezählt.

Einreichung absenden

POST/api/partner/submit-filing

Erstellt das PDF und versendet es physisch per USPS Certified Mail ans IRS. Du erhältst eine Tracking-Nummer. Zwei Modi:

  • Mit signed_pdf_base64: Bereits unterschriebenes PDF hochladen — wir überspringen die Generierung
  • Ohne signed_pdf_base64: Wir generieren das PDF aus den Formulardaten und fügen einen E-Signatur-Block ein

Feld-Strukturen

foreign_owner (erforderlich für 5472_1120)

{ "name": "Max Mustermann", // erforderlich: vollständiger Name des Eigentümers "country": "DE", // erforderlich: ISO-Ländercode — DE, GB, FR … → Part II Zeile 4c "address": "Musterstr. 1, Berlin", // optional: Wohnadresse (ausländisch) → Part II Zeile 4a "us_tin": "123-45-6789", // optional: US-Steuernummer / ITIN des Eigentümers → Part II Zeile 4b(1) "ftin": "DE123456789", // optional: ausländische Steuernummer (FTIN) → Part II Zeile 4b(3) "ref_id": "REF-001", // optional: Reference ID number → Part II Zeile 4b(2) "ownership_pct": 100 // optional: Beteiligungsquote in % }

transactions (optional, für Form 5472)

Array von Transaktionen zwischen der LLC und dem Auslandseigentümer im Steuerjahr. Jede Transaktion wird einem Form-5472-Part-IV-Feld zugeordnet.

typeForm 5472 ZeileRichtung
services_received15LLC erbringt Leistungen an den Eigentümer und erhält dafür Vergütung
rent_received13aLLC erhält Miete
royalties_received13bLLC erhält Lizenzgebühren
loan_from_owner17a / 17bLLC leiht Geld vom Eigentümer — Anfangs- und Endbestand (amount_beginning / amount_ending)
services_paid29LLC zahlt für Leistungen an Eigentümer
rent_paid27aLLC zahlt Miete an Eigentümer
royalties_paid27bLLC zahlt Lizenzgebühren an Eigentümer
loan_to_owner31a / 31bLLC leiht Geld an Eigentümer — Anfangs- und Endbestand (amount_beginning / amount_ending)
capital_contributionPart V Zeile 37Kapitaleinlage des Eigentümers (IRS-Pflichtfeld für foreign-owned DEs)
distributionPart V Zeile 38Ausschüttung an Eigentümer (IRS-Pflichtfeld für foreign-owned DEs)

Form 5472 wird als 3-seitiges PDF generiert: Seite 1 (Part I–III + Part IV Einnahmen), Seite 2 (Part IV Ausgaben + Transaktionsübersicht), Seite 3 (Part V — Pflichtangaben für foreign-owned DEs gemäß Reg. sec. 1.6038A-2(b)(7)(x)).

[ { "type": "services_received", // erforderlich: Typ aus Tabelle oben "amount": 5000, // erforderlich: Betrag in USD "note": "Software development" // optional: Beschreibung }, { "type": "loan_from_owner", // Darlehen: amount_beginning + amount_ending statt amount "amount_beginning": 10000, // Darlehensstand Jahresbeginn → Zeile 17a "amount_ending": 8000, // Darlehensstand Jahresende → Zeile 17b "note": "Owner loan" } ]

partners (erforderlich für 1065)

Array aller Partner der LLC. Die API generiert automatisch ein Schedule K-1 pro Partner — als zusätzliche Seiten im 1065-PDF (für das IRS) und als separate PDFs im Response-Feld k1_pdfs (zur Weitergabe an jeden Gesellschafter).

[ { "name": "Max Mustermann", // erforderlich "country": "DE", // erforderlich: ISO-Ländercode — DE = Deutschland, GB = UK "ownership_percent": 50, // erforderlich: Beteiligungsquote in % (alle Partner zusammen = 100) "address": "Musterstr. 1, 10115 Berlin", // optional: Wohnadresse des Partners (erscheint auf K-1) "tin": "DE123456789", // optional: ausländische Steuernummer (FTIN/SSN/ITIN) "partner_type": "general" // optional: "general" (Standard) oder "limited" } ]

financials (optional)

Alternativ zu transactions: Gesamtsummen statt Einzelbuchungen. Wenn gross_revenue gesetzt ist, werden transactions für die Einnahmen/Ausgaben-Berechnung ignoriert.

{ "gross_revenue": 50000, // Gesamteinnahmen in USD "expenses": { "payroll": 10000, // Löhne und Gehälter "rent": 2000, // Miet- / Leasingkosten "software": 500, // Software und Tools "professional": 3000, // Beratungs- / Anwaltskosten "other": 1500 // Sonstige Ausgaben } }

Einstellungen

GET/api/partner/settings

Gibt Partner-ID und aktuelle Webhook-URL zurück.

PATCH/api/partner/settings

Webhook-URL aktualisieren.

// Webhook-URL setzen { "webhook_url": "https://dein-system.com/webhook" } // Webhook entfernen { "webhook_url": null }

Webhooks

Webhook-URL in den Einstellungen hinterlegen. Bei jeder Statusänderung senden wir einen POST mit Content-Type: application/json und dem Header X-MyTaxFly-Event.

Events

  • filing.submitted — Einreichung erstellt, Versand noch ausstehend
  • filing.mailed — Brief erfolgreich per USPS Certified Mail versendet
  • filing.failed — Fehler beim Versand
  • webhook.test — Testnachricht (ausgelöst über Dashboard)

Payload

{ "event": "filing.mailed", "filing_id": "uuid...", "external_id": "client_001", "form_type": "5472_1120", "tax_year": 2024, "status": "mailed", "is_test": false, "letter_id": "ltr_...", "tracking_number": "9400111899223399401", "timestamp": "2024-03-15T10:05:00Z" }

Dein Endpunkt muss innerhalb von 10 Sekunden HTTP 2xx zurückgeben. Zustellversuche werden im Webhooks-Tab protokolliert.

Alle Einreichungen erfolgen per USPS Certified Mail mit Tracking. Die IRS-Adresse wird automatisch anhand des form_type gewählt — kein manueller Eingriff nötig. Wir gehen davon aus, dass die LLC keinen US-Geschäftssitz hat (typisch für ausländische Eigentümer).
