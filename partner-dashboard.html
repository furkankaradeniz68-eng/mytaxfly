Authentication

All requests require your API key in the X-API-Key header.

X-API-Key: mtf_live_xxxxxxxxxxxxxxxx

The system is currently running in test mode — letters are created but not physically mailed. No action needed on your side.

Typical Flow

The recommended flow for submitting a signed filing:

  • 1. Call POST /preview-filing with form data → receive pdf_base64
  • 2. Show PDF to client for review and signature
  • 3. Call POST /submit-filing with signed_pdf_base64 → letter mailed to IRS
  • 4. Receive status update via Webhook (if configured)

Preview Filing

POST/api/partner/preview-filing

Generates the tax form as a PDF and returns it as Base64. Use this to show the client a preview before signing.

Request Body

FieldTypeDescription
external_idrequiredYour own ID for this client/filing
form_typerequiredSee Form Types below
tax_yearrequiredNumber, e.g. 2024
company.namerequiredLLC name
company.einrequiredEIN, e.g. "12-3456789"
company.address.cityrequiredRegistered city
company.address.staterequired2-letter state, e.g. "DE"
company.address.streetoptionalStreet address
company.address.zipoptionalZIP code
foreign_ownerrequired for 5472_1120Object with name, country
transactionsoptionalArray of transaction objects for Form 5472
partnersrequired for 1065Array of partner objects
financialsoptionalFinancial data object
extend_formoptionalFor 7004: form being extended, default "1120"

Response

{ "pdf_url": "https://...", // signed URL, valid 24h "pdf_base64": "JVBERi0x...", // full PDF as Base64 "form_type": "5472_1120", "tax_year": 2024, "external_id": "client_001" }

Submit Filing

POST/api/partner/submit-filing

Submits the filing to the IRS via physical mail. Two modes:

  • With signed_pdf_base64: Upload the signed PDF directly — generation is skipped
  • Without signed_pdf_base64: We generate the PDF and embed an e-signature block

Request Body

FieldTypeDescription
external_idrequiredMust match the preview-filing call
form_typerequiredSee Form Types below
tax_yearrequiredNumber
companyrequiredSame as preview-filing
signer_namerequiredFull name of the signer
signer_titlerequiredTitle, e.g. "Managing Member"
signed_pdf_base64optionalPre-signed PDF as Base64 — skips generation
ip_addressoptionalClient IP for e-signature record
foreign_ownerrequired for 5472_1120Same as preview-filing
transactionsoptionalSame as preview-filing
partnersrequired for 1065Same as preview-filing

Response

{ "filing_id": "uuid...", "status": "faxed", // or "submitted" "letter_id": "ltr_...", // mail provider ID "tracking_number": "9400...", // USPS tracking "expected_delivery": "2024-04-05", "pdf_url": "https://...", // signed URL, 7 days "external_id": "client_001", "form_type": "5472_1120", "tax_year": 2024 }

Duplicate submissions (same external_id + form_type + tax_year) are rejected with HTTP 409.

Webhooks

Configure a webhook URL in Settings. We send a POST request with Content-Type: application/json and the header X-MyTaxFly-Event on every status change.

Events

  • filing.submitted — filing created, mail pending
  • filing.mailed — letter sent via USPS Certified Mail
  • filing.failed — an error occurred

Payload

{ "event": "filing.mailed", "filing_id": "uuid...", "external_id": "client_001", "form_type": "5472_1120", "tax_year": 2024, "status": "faxed", "letter_id": "ltr_...", "tracking_number": "9400...", "timestamp": "2024-03-15T10:05:00Z" }

Your endpoint must return HTTP 2xx within 10 seconds. Failed deliveries are logged in the Webhooks tab.

Form Types

1065Form 1065 — partnership return

All filings are mailed to the IRS via USPS Certified Mail. LLCs are assumed to have no US principal office (P.O. Box 409101, Ogden UT 84409 for 1065/1120; PIN Unit for 5472+1120).
